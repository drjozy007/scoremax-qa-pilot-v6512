# ScoreMax V6.2.7 — Reviewer Assurance & Navigation

V6.2.7 adds a confidential Academic Reviewer Workspace, Teacher of the Year Coming Soon public campaign, and accessible persistent student subnavigation.

## Current boundary

This remains a controlled-pilot build. Reviewer decisions do not publish questions and do not create student attempts or mastery. Real browser, mobile, accessibility, email-delivery and confidentiality acceptance remain required.

## Start locally

```bash
python app.py
```

Or use `start_scoremax_v6_2_7.bat` on Windows.

## Upgrade

Use `migrate_v6_2_6_to_v6_2_7.py` against a copied V6.2.6 database first. See `V6_2_7_MIGRATION_GUIDE.md`.
