# V6.2.3 to V6.2.4 Migration

No database migration is required.

1. Back up the current V6.2.3 folder and database.
2. Extract V6.2.4 to a separate folder.
3. Copy the database only after creating a backup.
4. Start V6.2.4 and run the browser acceptance checklist.
5. Retain V6.2.3 as rollback until acceptance is complete.
