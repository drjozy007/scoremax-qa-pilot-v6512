# V6.5.0 superseded release-identity assertions

Four inherited tests contained assertions that intentionally required a V6.3.2/V6.4.0 release marker or build name. Those assertions describe the parent release identity rather than functional behavior, so V6.5.0 preserves the original files under `historical_acceptance/v6_5_superseded_release_assertions/` and broadens only those release-identity assertions to recognise the additive V6.5.0 child.

No learner UX, mastery, referral, payment, chapter-identity, or other functional assertion was removed or weakened.
