# ScoreMax V6.2.5 Browser and Pilot Acceptance Checklist

## Daily Spark — student experience

- [ ] Dashboard shows one compact Daily Spark module rather than separate long sections.
- [ ] Academic Spark and Word of the Day tabs work with mouse, touch and keyboard.
- [ ] A real FSc student receives content only from the correct programme.
- [ ] A programme with no approved bank receives no borrowed Academic Spark.
- [ ] A real account never receives `[DEMO]` Academic Spark content.
- [ ] Refreshing the page keeps the same Spark for the day.
- [ ] The following day selects a different word where unused words remain.
- [ ] A recently missed approved question is reasonably prioritised.
- [ ] Correct and incorrect answers show the governed explanation.
- [ ] One Spark answer does not change formal mastery, exam projections or test counts.
- [ ] Double-clicking or resubmitting cannot create two answer records.
- [ ] Save, Later, Dismiss and Report work and remain owned by the logged-in student.
- [ ] Later hides the selected Spark during the cooling-off period and restores it afterward.
- [ ] Report captures Spark/source context without asking the student for technical IDs.
- [ ] Hiding either feature removes it immediately, including existing daily assignments.

## Word of the Day

- [ ] Definition is initially concealed and revealed intentionally.
- [ ] Pronunciation, example, synonym/antonym and use prompt display cleanly when available.
- [ ] Vocabulary is appropriate to the learner age/level.
- [ ] General vocabulary is not restricted to the English syllabus.
- [ ] No external AI/API call occurs when the card loads.

## Sustainability

- [ ] Public page is reachable without login.
- [ ] It is placed under About/More/footer, not the core learning navigation.
- [ ] Current Practice, In Progress and Future Commitment labels are visually distinct.
- [ ] Every public commitment shows owner and evidence/baseline context.
- [ ] Future targets are never presented as completed achievements.
- [ ] Admin can update blocks, policies, commitments and progress reports.
- [ ] Growth Engine JSON remains `DRAFT_REVIEW_REQUIRED` and does not publish.

## Accessibility and responsive behaviour

- [ ] Daily Spark tabs work with Arrow keys, Home and End.
- [ ] Focus is visible on options, tab buttons and actions.
- [ ] Screen-reader labels clearly identify the two Spark streams.
- [ ] At 200% zoom, no content or action is lost.
- [ ] Mobile layout does not create horizontal scrolling.
- [ ] Reduced-motion preference remains respected.

## Analytics

- [ ] Impression is counted once per student/assignment.
- [ ] Reveal, answer, save, dismiss and report events appear in Admin analytics.
- [ ] Open/completion rates use deduplicated events.
- [ ] Engagement can be compared by Academic versus Word stream.
