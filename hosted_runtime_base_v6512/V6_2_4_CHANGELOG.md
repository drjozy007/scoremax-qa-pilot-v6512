# V6.2.4 Changelog

## Fixed
- Students whose programme has no content no longer inherit every live chapter from unrelated programmes.
- Current-study subject availability, chapter lists and accuracy are now programme-scoped.
- Explicit unknown assessment targets no longer fall back to another bank.
- Removed the dead four-level mastery ordering dictionary.

## Accessibility foundations
- Skip-to-content link and focusable main landmark.
- ARIA-linked tab and tabpanel pattern.
- Left/right/Home/End keyboard tab navigation.
- Visible focus indicators and reduced-motion support.
- Escape, focus return and focus containment for the mobile menu.
