# ScoreMax V6.4.0 — Windows Founder Walkthrough

## One-click local start

1. Extract the V6.4 ZIP to a normal folder. Do **not** open/run files from inside the ZIP.
2. Double-click `INSTALL_AND_START_SCOREMAX_V6_4.bat`.
3. If packages are missing, the launcher installs `requirements.txt` automatically.
4. Keep the command window open.
5. Open `http://127.0.0.1:5000` in Edge or Chrome.
6. Register a normal student account and use the exact email or assigned ScoreMax ID to log back in.

V6.4 creates its own local database:
`internal_live_data/scoremax_v6_4_0_internal_live.db`
