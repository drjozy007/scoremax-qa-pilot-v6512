# ScoreMax V6.4.0 — Live Pilot UX & Operations Candidate

**Status:** `LIVE_PILOT_CANDIDATE_PENDING_DOMAIN_AND_FOUNDER_BROWSER_ACCEPTANCE`

V6.4.0 is a controlled descendant of the sealed ScoreMax V6.3.2 Governed Chapter Identity candidate.
It consolidates the student-experience changes agreed during the founder walkthrough and adds the minimum
operational foundations needed for the live pilot: persistent programme context, a mastery-centred Home,
teacher referral attribution/reporting, a governed 3,000-row Emergency Direct Intake fallback, and hosted-pilot
configuration/health identity.

Academic reviewing remains a **Power House** responsibility. ScoreMax does not create academic approval or
invent missing Knowledge Node / Claim Family / Reasoning Seed identities.

## Fastest Windows start

1. Extract the ZIP to a normal folder (do not run from inside the ZIP).
2. Double-click `INSTALL_AND_START_SCOREMAX_V6_4.bat`.
3. Open `http://127.0.0.1:5000`.

For the full local acceptance replay, run `RUN_SCOREMAX_V6_4_ACCEPTANCE.bat`.

Read `START_HERE_V6_4.txt`, `README_SCOREMAX_V6_4_0.md`, and `V6_4_0_LIVE_AUDIT_STATUS.md` before deployment.
