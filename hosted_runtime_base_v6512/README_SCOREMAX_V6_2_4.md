# ScoreMax V6.2.4 — Curriculum Isolation & Accessibility Foundations

This release supersedes V6.2.3. It fixes cross-programme content leakage and adds the first deliberate keyboard/accessibility layer to the compact student experience.

## Key rule
A student may see only content that matches their current programme or qualification. If no bank exists, ScoreMax shows declared/catalogue subjects as **Coming Soon** rather than borrowing another programme's questions or chapters.

## Start
Run `start_scoremax_v6_2_4.bat` or `python app.py`. No database migration is required from V6.2.3.
