# ScoreMax V6.2.6 Assurance Gate Model

## Gate 1 — Content Admission

Checks mandatory non-release flags, supported families, relationship identity, lineage/warnings and candidate presence. Warnings remain visible; structural failures block the batch.

## Gate 2 — Assessment Execution

Challenges every imported family with its governed correct response and a generated incorrect response. Confirms family-specific scoring does not collapse to single-choice behaviour.

## Gate 3 — Mastery and Study Plan

Confirms completed synthetic runs use a valid state, preserve a rationale and create no live attempts or mastery records. The next action is advisory laboratory output only.

## Gate 4 — Security, Privacy and Isolation

Confirms separate QA tables and mandatory release flags. A collision with an existing live external question ID becomes a blocker requiring explicit admission reconciliation.

## Gate 5 — Release Acceptance

Requires evidence from Gates 1–4 and no open blockers. A pass means only:

> The Mastery Laboratory technical milestone is accepted for QA use.

It does not mean:

- questions are academically approved;
- questions may be published;
- real students may use the corpus;
- synthetic mastery may become real mastery.
