# V6.2.8 Student Navigation Contract

## Desktop and laptop

Primary row:

Dashboard | Learn | My Plan | Tests | Exams | Progress | Knowledge | More

A second persistent horizontal row displays contextual destinations for the active primary section. Normal navigation must not open a popup window, mega-menu overlay or dropdown panel.

## Mobile and small tablet

A reduced bottom navigation preserves the highest-frequency destinations. The active section's contextual destinations remain available in a compact horizontally scrollable row.

## Subject switcher

The programme-scoped subject row appears across Dashboard, Learn, My Plan, Tests, Exams and Progress. It shows Included, Locked and Coming Soon states and never borrows content from another programme.

## Accessibility

Navigation must retain semantic links/buttons, visible focus, keyboard activation, active-state indication and tap-friendly controls. Horizontal overflow is limited to the compact navigation rows rather than the page body.
