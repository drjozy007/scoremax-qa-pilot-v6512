# ScoreMax V6.2.7 Changelog

## Added

- confidential Academic Reviewer Workspace;
- minimal reviewer-only portal with no normal ScoreMax shell;
- JSON/CSV/XLSX review-batch import up to 100 questions;
- named reviewer accounts and one-time time-limited invitations;
- reviewer-specific watermark and confidentiality acceptance;
- one-question-at-a-time quiz-style review;
- autosave, completed/current/remaining navigator and exact resume;
- active-time tracking per item and per assignment;
- hidden-tab and inactivity-aware client timing;
- answer-reveal, return-visit and edit records;
- explicit review decisions and compulsory comments;
- independent second-review and adjudication routing;
- Admin progress, timing, calibration and risk-pattern evidence;
- Teacher of the Year Coming Soon landing-page feature and public page;
- sticky accessible student navigation with click/focus/hover/tap submenus.

## Security and governance

- reviewer sessions are fenced away from all normal ScoreMax routes;
- review snapshots do not contain student data, live-bank architecture, concept/LO ledgers, source lineage or mastery-engine rules;
- no direct publishing or promotion path exists;
- no bulk reviewer export exists;
- timing is never used as an automatic acceptance or rejection rule.
