# ScoreMax UX vNext — Design Intent

Status: design-only working note; no production release conferred.

## Product objective
Create a fascinating but highly usable learner-facing experience: modern, energetic and intelligent without visual clutter or internal-system language.

## Non-negotiables
- No learner-facing internal terms such as Power House, Growth Engine, QA, qualification, build IDs, release IDs, runtime, firewall, pipeline, reviewer internals or deployment terminology.
- Restore the six-stage learner progression journey: Foundation → Exam Ready → Advanced → Distinction → Expert → Elite.
- Replace brain/anatomical imagery with digital-learning / learning-intelligence / technology-led visual language.
- Remove oversized black full-viewport treatment from the landing page.
- Mobile is a first-class composition, not a stacked desktop afterthought.
- Primary user journey must remain obvious: identify programme → understand progression → start practice / sign in.

## Visual direction
- Bright, modern education technology rather than dark gaming aesthetic.
- Strong whitespace and hierarchy.
- Restrained gradients / glass effects only where they improve orientation.
- Distinct but consistent progression stages.
- Large tap targets, legible typography and short decision paths.
- Fascination comes from motion cues, intelligent data/progression metaphors and polished micro-interactions—not dense decoration.

## Build order
1. Global shell and navigation
2. Landing page
3. Login / registration / password reset
4. Student shell and dashboard
5. Assessment experience
6. Teacher interface

## Governance
All work happens on an isolated UX branch. Production scoremax.pk remains unchanged until explicit approval after staging review and automated desktop/mobile regression.
